# Asset contract

No Fallout Shelter art is copied. This project uses its camera/room/interaction principles, not Bethesda files.

Place original or properly licensed room images under `rooms/`, resident sprites under `residents/`, and media previews under `previews/`.

All assets must have source/provenance metadata. Identity-locked residents must never receive generic AI-generated replacements. The first milestone intentionally uses geometric stand-ins.
