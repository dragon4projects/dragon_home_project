# TEEA008 physical book route review
Candidate live mode only. A physical title stays at its source library while a resident reserves the pickup. A measured bookshelf approach is required; holder changes only on arrival. The actor then travels to a compatible reading seat, accumulates actual simulation reading time, and walks back to the source shelf. Competing reservations and remote pickup denied. Failed seat claim returns at the already reached shelf. Stale routes and daily reset are reconciled. Engine test PASS across save/restart during pickup, acquisition, read, return, competing reservation denial and reference-only exclusion. This is room/shelf station-level possession; per-volume shelf slot graphics and hand contact are not yet verified. Standard production remains unchanged. No owner approval.
