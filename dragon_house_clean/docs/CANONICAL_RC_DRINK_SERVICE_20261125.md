# Drink source routing

The physical pickup station remains reserved until the cup returns. A selected new drink now routes to a reachable coffee machine or bar in that same room before filling; the source is temporarily reserved separately. Partial cups resume without another source visit or new choice. Sip/return cannot silently teleport a cup to a table: approach distance is checked. Failed source/replan logs a failed choice without learning. Source location is derived from authored counter bounds, not guessed screen coordinates. Existing IDLE hand contact is retained rather than inventing a verified sip animation. Tests cover real bar traversal, four rooms' source approaches, label on hand/table, empty label, actual snapshot reload. No intermediate exports. Runtime verification pending.
