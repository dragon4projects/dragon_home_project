# Private cinema catalog recovery

Private pack remains outside public GitHub. Local source records use FILMIX_<numeric poster/source card ID>, with source page and original embedded preview, checksum, title/year/type and source-backed duration evidence. The earlier v3 payload could not be recovered, so historical runtime counts are not claimed. The importer validates the whole incoming batch before changing the in-memory catalog, rejects duplicate/path/type/invalid-duration records, validates optional preview SHA256, preserves old positive timings when incoming values are unknown, preserves earlier verified season boundary flags and progress IDs, and strips external playback fields. Missing file leaves previously installed records intact (obsolete YouTube classification is separately archived). Existing old catalog IDs may differ from the reconstructed numeric scheme: no speculative identity remap is performed. Duration edition discrepancies must be resolved at authoring, not by substituting a default. Tests use synthetic fixtures only. Engine not executed; source data validation and actual install remain distinct.
