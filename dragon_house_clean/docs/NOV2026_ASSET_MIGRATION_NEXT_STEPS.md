# Dragon House. Следующие шаги переноса

## Доставка

1. Восстановить авторизацию Git Credential Manager для приватного dragon4projects/songs_panels. Получить текущую вершину dragon-house-fallout-fresh и проверить пути в dragon_house_clean/.
2. Настроить Git LFS в рабочей копии. Скопировать подготовленные пути с проверкой совпадений и действующих файлов. Сначала перенести проверенные мастера и банки жителей. Материалы с неустановленными правами держать вне отправки.
3. Сделать обычный push, перечитать удалённый HEAD и контрольную выборку бинарников через LFS. Сверить SHA‑256 загруженных файлов.

## Проверка материалов

- Утвердить точные банки RES_22, RES_23 и RES_24. Для HOME ЭВМочки проверить отдельно DRINK и CARRY_USE. Список найденных записей по трём жительницам находится в unresolved_assets.json.
- Сверить размещение кадров в атласах и порядок анимаций. Выполнить покадровый просмотр масок, обрезки и поз. Проверить связку с новым runtime на Windows/Compatibility отдельным изменением.
- Согласовать слои и ширины помещений, права владельцев закрытых комнат и соответствие превью каноническим книгам, фильмам и музыке.
