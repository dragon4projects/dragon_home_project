# Cinema simulation contract — owner correction 2026-11-25

No video playback for film/series. Filmix bookmarks are separate from the ZNA YouTube preview dataset. Previous generated film classification records are archived in local runtime_state, not silently destroyed; the source manifests remain unchanged. Private bookmarks and posters are imported from user://filmix_catalog.json plus user://filmix_previews/<id>.webp, never committed to this public repository. The pack is locally supplied. Catalog entries use explicit film runtime_seconds or ordered episode_runtime_seconds per season, sourced from verified episode guides. Unknown duration is visible but not eligible for autonomous watching. Earlier season arrays must contain the complete verified season; latest season may be limited by the source snapshot.

On physical arrival, the session starts, with until = current simulation clock + verified duration (seconds). No mid-session planner reschedule; completion is recorded once, per resident and title. Film is complete; series progresses to next episode/season if known, then returns to ordinary activity with an intermission before subsequent selection. Independent progress per resident persists in runtime_state. No credit for a partial/aborted session. For initial safety one uninterrupted screening is reserved per cinema (no late-join false completion). Main screen uses existing bound preview path and hover/viewer. Television uses independent selection. Actual engine validation still pending; no GitHub Actions run.
