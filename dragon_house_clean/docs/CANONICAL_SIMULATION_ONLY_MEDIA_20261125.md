# Consolidated requirements D03/D04 (music portion)
Removed real media player nodes, UI playback/stop/source controls, decoder and external launch paths from both catalog UI and fullscreen viewer. Legacy play methods are intentionally inert; playable() returns no actual playback candidates. Legacy records remain browseable even without local audio/video bytes. Music repeat eligibility now has a per-resident hard 86400 simulation-second boundary, also checked at selection and arrival, preserving independent histories. Repeat weight gradually recovers over seven game days (tunable engineering choice); new material remains favored. Film/series replay and book preference changes are separate. Shared late attendance is not implemented by this change. Godot execution pending.
