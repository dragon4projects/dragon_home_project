# Cinema continuity closure
Film completion has a one simulated day cooldown, then is eligible for a deliberate replay. Counts and total viewing seconds persist. In-progress series receive continuation preference; previously finished movies do not monopolize subsequent visits. Season boundaries require explicit complete_seasons evidence. Exhausting a partial episode table stops eligibility until metadata is filled, not a false leap to the following season. When metadata is later marked complete, next_watch_unit can advance the previously blocked boundary. A series caught up to the source snapshot awaits additional episodes. Test fixtures cover replay, separate resident progress, exact time and partial season behavior. Godot execution remains pending.
