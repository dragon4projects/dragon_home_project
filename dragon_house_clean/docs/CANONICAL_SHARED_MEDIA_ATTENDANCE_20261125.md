# D05/D06 / A14 shared media

One persisted program per currently supported primary cinema-screen or audio source, keyed by room and category; separate rooms independent. Members carry individual join time, original program ID/deadline and full-credit flag. The program is validated against source-backed duration, actor arrival and matching membership. Full credit requires arrival at program start and eligibility for that exact episode/track; later/out-of-sequence attendance has no completion or progression, but records attended time separately. Cancellation settles only attendance; when the final member leaves the program ends. A due program is retained until its attendees settle. No device replacement during a running program. Life planner chooses current work on destination; arrival can retarget to the actual current program, otherwise fail/replan without credit. Binding preview reads active program, then pin. Legacy compatible actor-local saved sessions adopt original timing; mismatched/invalid sessions are cancelled, not restarted/credited. Normal reload restores persisted program and participant eligibility. Catalog duration changes that invalidate original timing fail closed. Legacy series caught-up rows migrate to completion, individual timestamps conservative where absent. Eligible continuation gets priority as a class, most recent first; new vs repeat weight recovery retained. No real playback. TV/gamepad remains independent semantic surface, not a second timed-film device; additional same-room timed devices would require explicit carrier-specific station mapping. Shared state is persisted in world snapshot/journal, not yet full event-sourced causal replay. No Godot execution available here. Regression scenarios in test_shared_media_attendance.gd and test_timed_media_reload.gd.
